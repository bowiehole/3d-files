# Cybertruck rack → DJI Mic 3

Holds a DJI Mic 3 on a Cybertruck rack. Plate bolts to the rack; mic holder slides onto the pole; printed nut locks it.

## Files

| File | What |
|------|------|
| `rack-mount.stl` | Rack plate with two bolt holes and a vertical pole |
| `mic-holder.stl` | Cylinder that holds the DJI Mic 3; hole fits the pole |
| `nut-m6.stl` | Printed M6 hex nut |
